📖 Manuel d'Utilisation

1. Saisie des Crédits & Saisie Prédictive Intelligente

Lorsque vous rédigez la description d’un élément dans l’onglet Credits (boutons ✨ Style ou 🏠 Décors), le champ Marque intègre un systeme d’auto-complétion connecté en temps réel à votre base locale :

  • Saisie assistée : Dès que vous tapez un minimum de 3 caractères, l’outil cherche une correspondance parmi vos Sponsors ou vos Événements enregistrés. S’il trouve un résultat, il remplit automatiquement le nom complet et injecte instantanément les informations rattachées (Lien SLURL, nom du Manager).
  • Sauvegarde Express (💾) : Si la marque tapée n’existe pas encore dans votre base de données, une icône de disquette dorée 💾 apparaît à côté de son titre. Cliquez dessus pour l’enregistrer immédiatement dans votre répertoire global sans interrompre la composition de votre post.
  • Multi-adresses (Multi-SLURL) : Vous pouvez saisir plusieurs liens pour un même créateur en les séparant par le caractère vertical | (ex: LienMagasin | LienMarketplace). L'outil s'occupera de créer proprement les liens numérotés (Store 1, Store 2...) dans vos rendus finaux.

2. Gestion de l'affichage : Cloisonnement "Style" vs "Décors"

Pour éviter l'encombrement visuel et les erreurs d’attribution, les menus déroulants de sélection de catégories sont étanches :

  • L'onglet ✨ Style affiche exclusivement les catégories relatives à l’avatar et à l'habillement (ex: Outfit, Corps, Shape, Peau, Cheveux, Bijoux...).
  • L'onglet 🏠 Décors affiche quant à lui les éléments environnementaux (ex: Backdrop, Meubles, Végétaux, Poses, Animaux...).

💡 Note sur les Réseaux & Aperçus : Afin de maximiser l’espace de travail lors des phases d’édition complexes, la barre inférieure des rendus (Aperçus Flickr et Primfeed) est automatiquement masquée lorsque vous naviguez sur l’onglet Profil, et réapparaît sur les onglets de rédaction.

3. Formulaire Unique de Modification des Catégories

Dans l’onglet Profil, la section Personnalisation des Catégories liste l’intégralité de vos critères de tri. Pour modifier une structure existante, cliquez sur l’icône de crayon ✏️ :

  • Un **formulaire modale unifié** apparaît à l'écran, regroupant simultanément l'ensemble des données configurables.
  • Vous pouvez librement renommer son libellé en Français, changer son Émoji graphique, spécifier sa traduction en Anglais (utilisée lors de la compilation finale de vos templates), ou changer son type de destination (Style ou Décors) via un menu déroulant dédié.
  • Cliquez sur Enregistrer pour valider les modifications globales. Le script ré-indexe automatiquement tous vos menus déroulants en arrière-plan.

4. Gestion Avancée des Deadlines & Alertes Visuelles

L'outil intègre un tableau de suivi temporel des livraisons pour vos partenariats de blog ou de contenu :

  • Code couleur dynamique : Le voyant d'état d'une marque passe automatiquement au vert si la date butoir est supérieure à 5 jours, au jaune orange à J-5, et vire au rouge critique à J-2 ou moins.
  • Badge d'Alerte : Dès qu’une seule de vos échéances atteint le seuil critique des 48h (J-2), un point rouge clignotant se fixe sur le bouton ⏳ Deadlines de votre menu principal pour attirer votre attention, même si vous travaillez sur un autre onglet.

5. Éditeur de Modèles (Templates) & Injecteurs de Balises

Vous pouvez gérer une infinité de structures de mise en forme pour vos textes via le gestionnaire de modèles :

  • Sélectionnez le modèle actif via le menu déroulant pour modifier son comportement.
  • Modifiez directement le squelette textuel dans la zone d'édition. Pour ajouter une section dynamique, placez votre curseur à l'endroit désirez et cliquez sur les boutons injecteurs rapides (＋ Titre, ＋ Style, ＋ Décors...). Le script y insérera la balise correspondante.

6. Système de Sauvegarde, Importation & Exportation (Backup)

Toutes vos bases de données sont stockées localement dans votre navigateur. Pour sécuriser votre travail :

  • Utilisez le bouton Exporter JSON pour télécharger un fichier de sauvegarde physique complet (.json).
  • En cas de changement de machine, utilisez Importer JSON pour restaurer l'intégralité de vos configurations en un instant.
